# مجلد الصوت

ضع هنا ملف الإنذار باسم:

  fire-alarm.mp3

المسار المتوقع من الكود: `assets/audio/fire-alarm.mp3`

إذا لم يكن الملف موجودًا:
- لن يتعطل المشروع
- سيُطبع Warning واضح في Console
- سيعمل إنذار بديل عبر WebAudio (oscillator) حتى يستمر التدريب
- ستستمر بقية المحاكاة (الإضاءة الحمراء، الأسهم، الإخلاء)

للمعاينة السريعة يمكنك وضع أي ملف MP3 لصفارة إنذار بهذا الاسم.
