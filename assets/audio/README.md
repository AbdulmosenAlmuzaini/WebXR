# مجلد الصوت

الملفات المطلوبة (موجودة حاليًا وجاهزة للتشغيل):

| الملف | الوصف | السلوك |
|---|---|---|
| `fire-alarm.mp3` | صوت إنذار حريق ثنائي النغمة (~4 ثوانٍ، يعمل Loop) | يبدأ مع حالة الطوارئ، يستمر حتى الوصول للباب، ينخفض إلى 50% بعد 10 ثوانٍ من عدم الحركة |
| `success.mp3` | رنين نجاح قصير وهادئ (~1.6 ثانية، بدون Loop) | يعمل مرة واحدة فقط عند الوصول إلى باب الخروج |

المسار المتوقع من الكود:
- `assets/audio/fire-alarm.mp3`
- `assets/audio/success.mp3`

نسخ مطابقة موجودة في `public/assets/audio/` حتى تُنسخ تلقائيًا إلى `dist` عند `npm run build`
وتعمل على Vercel بنفس المسار النسبي.

إذا حُذف أي ملف أو تعذّر تشغيله:
- لن يتعطل المشروع
- سيُطبع Warning واضح في Console
- سيعمل بديل عبر WebAudio (oscillator للإنذار / رنين صاعد للنجاح)
- ستستمر بقية المحاكاة (الإضاءة التحذيرية، الأسهم، الإخلاء)

لاستبدال الأصوات: ضع أي ملف MP3 بنفس الاسم في هذا المجلد وانسخه إلى `public/assets/audio/`.
